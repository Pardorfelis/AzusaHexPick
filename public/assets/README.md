# 界面素材来源

六幅阿梓图片由项目发起者溣符雨提供并指定使用。提供的素材清单将来源记为 [萌娘共享的阿梓分类](https://commons.moegirl.org.cn/Category:阿梓)，未附逐张作品的授权记录。图片版权属于原作者及相应权利人；项目不主张这些作品的版权，也不代表官方出品。未确认的二创作者不作推定署名。

| 项目文件 | 提供的原文件 | 用途 |
| --- | --- | --- |
| azusa-snack.jpg | Azitouxiang2.jpg | 操作台来源标题与静态替代图 |
| azusa-brand.png | 阿梓 logo.png | 操作台项目名称旁 |
| azusa-computer.png | 阿梓 侧边挂件.png | 桌面副屏结果旁与网页空状态 |
| azusa-panel-brand.png | 新logo阿梓.png | 桌面副屏右下角 |
| azusa-cheer.gif | 800动图.gif | 操作台来源状态旁 |
| azusa-sing.gif | 阿梓 同人3.gif | 操作台歌回名单标题旁 |
| azusa-wallpaper.jpg | 维护者提供的默认背景 JPG | 控制台默认背景，网页副屏可选 |

默认背景保持提供文件的原始字节，来源说明记录在 azusa-wallpaper.jpg.json。界面不显示默认背景的画师姓名，作者与版权归属由维护者在正式公开的 README 中补充；不推定缺失的原作品地址或授权条款。

图片保留原有像素、帧与透明通道，界面仅缩放或裁切显示。静态图片内附来源说明，GIF 的同名 JSON 文件保存来源说明。两张动图可以暂停，系统减少动态效果时显示静态替代图。如权利人希望更正来源或移除展示，可联系项目维护者溣符雨。

英文与数字使用 [Google Fonts 提供的 Manrope](https://github.com/google/fonts/tree/main/ofl/manrope)，字体随应用提供，遵循 fonts/OFL.txt 中的 SIL Open Font License 1.1。中文使用设备现有的微软雅黑、苹方等系统字体。界面图标使用项目内的 SVG。
