# 梓有妙选 · Azusa HexPick

当梓神海克斯大乱斗或歌回点歌时，把弹幕里的选择、出装讨论与歌名汇成一眼可读的结果。无需退出游戏或切换窗口，只需扭头看看副屏、低头看看手机，就可快速看懂弹幕建议。

这是阿梓粉丝制作的本机弹幕建议工具。项目仓库为 [Pardorfelis/AzusaHexPick](https://github.com/Pardorfelis/AzusaHexPick)，版本历史从 v0.3.0 开始。

项目发起与维护：溣符雨（BiliBili）。

当前版本为 0.5.0 本机验证版。支持真实回放和游客直播接入，共用海克斯计票、装备建议归并、弹幕点歌及副屏显示。海克斯支持重复数字、通用推荐短句、全部刷新与双选项刷新，每条消息最多一个完整动作。装备采用官方正式名目录、常见别名与可选 AI；反复出现的陌生名称单独展示为待确认线索。

- 海克斯选择和刷新共十种动作，重复数字每条只统计一票。
- 装备覆盖 411 个正式名、102 个别名，首选、反对和后续计划分开呈现。
- Windows 置顶副屏窗、全局快捷键，以及可选手机只读页。
- 随附脱敏 P3、P4 回放；装备和海克斯 AI 分别按需启用。
- 弹幕点歌允许同一观众反复点歌，支持单次候选、一键本场灰名单和限期黑名单，随附歌回 P1、P2。

## 界面版本

v0.5.0 统一操作台、网页副屏与 Windows 桌面副屏的视觉风格：以阿梓代表色为强调色，桌面来源与轮次设置并排，结果固定在右侧。使用六幅指定素材，项目名称旁展示阿梓 logo，桌面窗保留紧凑的计票表与歌曲列表。点歌名单、AI 设置及手机链接仍在原页面中。维护署名采用粉色强调，两张操作台动图可暂停。界面素材及字体来源见 [素材说明](public/assets/README.md)。

此版本发布在 [ui_design 分支](https://github.com/Pardorfelis/AzusaHexPick/tree/design/v0.5.0)，main 保留原界面。切回 main 或 v0.4.0 标签可比较旧版。两个版本使用同一个端口，请先停止正在运行的服务。

## 启动

需要 Node.js 22 或更高版本，以及带 Tkinter 的 Python 3.10 或更高版本。项目不需要安装 npm 或 Python 第三方依赖。

双击“启动.cmd”，打开操作台和桌面副屏窗。操作台地址为 http://127.0.0.1:5178。默认只允许本机访问，AI 默认关闭。

只使用网页时，可以运行 node server.mjs。

双击“停止.cmd”停止服务和助手。日志位于 .runtime，密钥不写入日志。

## 首次验证

1. 选择 P3 回放，定位到 24：40 的数字建议密集候选片段。
2. 选择海克斯模式、有效弹幕条数和 10 秒收集时长。
3. 播放并开始新轮，查看选择与刷新动作的条数和领先项。新版 10 秒片段应有 35 条建议，1、2、3 分别为 12、22、1。
4. 再选匿名标识实验口径，对比重复发言和改票的影响。
5. 装备模式可以用 P3 的 83：10、P4 的 26：10 附近片段，查看推荐、反对和待识别。

回放位置相对各自分 P。跳转和换分 P 会清轮；回放暂停会锁定本轮。候选片段依据弹幕密度筛选，仍需结合视频确认主播是否正在征求建议。

## 游戏中控制

- Ctrl＋Alt＋F7：新开海克斯轮次。
- Ctrl＋Alt＋F6：新开 60 秒点歌轮次。
- Ctrl＋Alt＋F8：新开装备建议轮次。
- Ctrl＋Alt＋F9：锁定当前结果。

桌面显示窗置顶并采用不激活样式。可拖动标题调整位置，点歌时可直接点击歌曲旁的「略过」。实际游戏环境仍需验证焦点行为，尤其是独占全屏的显示限制。

v0.5.1 支持拖动窗口边缘调整大小，拉高窗口增加可见歌曲。底部显示加减按钮调整字号及整个界面倍率，默认 125％，远距离看副屏可尝试 150％；尺寸与倍率会在本机记住。阿梓 logo 位于右下角。

## 模型与手机

密钥只填入本机 .env.local 的 DEEPSEEK_API_KEY。操作台不会显示密钥。装备和海克斯 AI 分别启用后才向 DeepSeek 发送对应未决文本，可选择 Flash 或 Pro。海克斯在末段且本地明确建议不足 20 条时才补充理解，数量够多则跳过。程序负责计数，模型只能返回受校验的解释。

双击“启动手机模式.cmd”可启动局域网只读页，随后在操作台复制配对链接，用同一网络的手机打开。手机只能看结果。需要实际手机确认网络、锁屏恢复及扫读，程序不会自动修改防火墙。

详细规则见 [使用说明](docs/usage.md)，实测记录见 [验证记录](docs/validation.md)。

## 歌回点歌

选择「弹幕点歌」，打开歌回 P1 的 46：30 或 P2 的候选片段进行验证。重复发送逐条计入，同一条弹幕反复写同一歌名计一次。至少出现两次进入主列表，明确单次点歌另列为候选，次数不决定主播应唱哪首。

歌曲旁一键加入本场灰名单，后续轮次继续过滤；开始新场或重启服务后清空。黑名单手动输入歌名，支持一周至永久，跨启动保留并在到期时自动移除。详见 [点歌说明](docs/songs.md)。

## 检查与打包

双击“验证.cmd”运行自动检查。它会启动独立测试端口，不连接真实直播或调用付费 AI。

运行 python -X utf8 scripts/package.py，生成 dist 中的 ZIP 和 SHA-256 校验文件。解压后保留相同目录结构即可使用，仍需上述运行环境。包内不包含 .env.local、运行日志或原始 XML；在其他电脑使用 AI 时，需要自行建立本机密钥配置。

当前便携包名称为 azusa-hexpick-0.5.1.zip。本次界面改版与后续桌面修复发布在 design/v0.5.0 分支，分别保留 v0.5.0、v0.5.1 标签，main 保留 v0.4.0。其他常规发布流程见 [版本发布约定](docs/releasing.md)，更新内容见 [更新记录](CHANGELOG.md)。

运行 python -X utf8 scripts/verify-package.py，可以核对压缩包清单，并在独立解压目录检查应用。

## 已知边界

匿名标识实验口径不是精确人数。回放文件不保证覆盖全部直播原始弹幕。5 秒视频延迟会使旧画面的纯数字回复进入新轮，清零无法可靠判断这些回复属于哪一轮。

装备目录和昵称表不保证覆盖新梗，尚未判断当前模式可购买性。未识别或歧义表达不能视为零意见，更不能由模型补出观众没有支持的推荐。主播端实战和真实手机验收尚需完成。
