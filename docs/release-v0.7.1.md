# v0.7.1 试用交付说明

梓有妙选｜Azusa HexPick。项目发起与维护：溣符雨（B 站）。本版是面向阿梓首次试用的交付完善版，版本号沿用 v0.7.1。

本文件说明本版功能与下载选择。实际发布状态和检查结果见 [验证记录](validation.md)，日常使用从官网下载安装即可。

## 本版重点

- 安装版增加可选目录和桌面快捷方式，便携版继续完整解压即用；两者使用相同的统计功能和独立个人设置。
- Fluent 云白官网集中展示功能、配乐演示、下载安装和图文教程。官网与离线教程共用正文，访客不能上传或切换背景。
- 手机只读区域显示一个推荐地址，其他网络地址折叠展示，避免把 VPN 和虚拟网卡地址并列推荐。
- 保留使用者手工修改的文案。反馈由我接收的叙述统一为第一人称，教程直接指导使用者，不反复直呼主播姓名。
- 教程补齐安装版和便携版各自的步骤、桌面快捷方式以及 Ctrl＋Alt 快捷键。海克斯技能选择和弹幕点歌统计目前较成熟，海斗装备建议仍标为测试中。
- 修复差量更新包被误判为损坏的问题，保留逐文件校验与受保护缓存凭据；损坏缓存可保留旧版运行并重新下载，个人设置和加密密钥继续保留。

## 下载选择

Windows 10／11 x64 电脑优先选择「AzusaHexPick-0.7.1-Setup.exe」。按照向导选择可写位置，默认创建桌面快捷方式，完成后打开「梓有妙选」。不需要另装 Node、Python 或 .NET。

便携版「AzusaHexPickApp-win-Portable.zip」需要完整解压到固定位置。对根目录「梓有妙选.exe」右键，选择「发送到 → 桌面快捷方式」；Windows 11 先选「显示更多选项」。不要把 EXE 单独移出目录。

安装版和便携版更新后保留 `%LocalAppData%\AzusaHexPick\UserData` 中的加密密钥、主题、背景、字号和长期黑名单。本轮统计及本场灰名单仍随服务重启结束，建议下播后更新。

## 官网与更新源

官网地址为 [azusa510.top](https://azusa510.top/)，采用香港 COS 静态托管。功能介绍、配乐演示、下载和教程集中在同一页。

官网、软件下载和视频采用同站托管；应用更新优先使用配置好的正式 HTTPS 更新源，GitHub 正式版本保留为备用。v0.7.0 原客户端仍需经 GitHub 获得这次过渡版本。测试版本不能进入正式更新渠道，未经验证的域名不能写入正式交付包。

官网 `baseUrl` 与客户端 `delivery.json` 的 `introductionUrl` 指向同一正式站点，`updateBaseUrl` 指向站内 `updates/`。安装向导的证据清单绑定版本、安装文件、内部载荷、完整更新包和发布地址；便携包另行核对内部版本清单、文件哈希和发布地址。正式官网构建拒绝预览目录及 `preview: true` 的安装向导。

## 本地预览与正式产物

日常使用请选择安装版或完整便携 ZIP，GitHub 的 Source code 是源码。维护者的编译中间目录和本地预览包不属于使用者下载内容。

正式 v0.7.1 必须齐备安装向导、便携 ZIP、完整 NUPKG、基于 v0.7.0 的差量 NUPKG 和 `releases.win.json` 引用的全部包，并附大小及 SHA-256 校验。官网构建的 `site-manifest.json` 绑定同一版本的正式域名、公开文件及哈希；部署前后分别核对本地文件和远端实际内容。
