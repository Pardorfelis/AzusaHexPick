# 结构与状态约定

~~~mermaid
flowchart LR
  A[游客直播源] --> E[PanelEngine]
  B[脱敏回放源] --> E
  E --> C[本地装备归并]
  E --> K[本地海克斯分层识别]
  K --> E
  K --> L[少量未决数字表达]
  L --> D
  C --> D[可选 DeepSeek 归并]
  D --> E
  E --> F[本机 HTTP 状态与事件]
  F --> G[操作台与副屏网页]
  F --> H[Windows 只读桌面窗]
  F --> I[配对手机页]
  J[全局快捷键助手] --> F
~~~

src/engine.mjs 是唯一计票状态来源，两个显示载体不会重新计票。回放和直播消息都统一为消息编号、文本、匿名来源、接收时间及源代次。

轮次状态为未开始、收集中、暂停和已锁定。断连停止收集；恢复连接开新轮。消息去重缓存跨轮保留且有界，回放跳转生成新的播放编号以允许重复试验。

装备归并不承担游戏推荐。它只整理观众表达中的首选、反对、先后、条件和备选。模型输出必须经过本地校验；状态层再次检查来源、轮次、版本和时限。

普通网页适合验证操作和扫读；Windows Canvas 负责不激活、置顶及原生快捷键，消费同一快照。修改接口字段时需要同时核查两个显示载体。

默认服务绑定 127.0.0.1。局域网模式绑定 IPv4 接口，只读页面要求随机配对令牌；控制、回放目录、健康与配置接口仅本机可访问。HTTP 控制还检查主机、来源、自定义请求头及 JSON 类型，静态文件使用白名单。

src/hex.mjs 只做受限文本识别，不计算票数。引擎保存精确指令、重复数字、明确短句及 AI 的累计计入数。AI 解释只能确认文本中已有的单个候选。明确反对更新匿名修订、撤回匿名支持，消息历史不倒扣；来源、轮次、修订和截止时间校验仍由引擎统一执行。

共享快照包含计数、状态和达到重复阈值的短装备候选词，不包含完整弹幕原文或匿名标识。本机 GET /api/hex-audit 和 GET /api/equipment-audit 各提供最多 20 条相关原文样本，手机令牌不授权这两个接口。样本随轮次清空，不建立持久直播原文日志。装备与海克斯 AI 开关独立，海克斯在末段且明确本地建议不足 20 条时才调用；阈值用于调用策略，不表示置信度。

海克斯的 d、12d、13d、23d 是完整动作，与原六项同级计票，不拆成单项票。陌生装备词只从有界未决记录提取和归并，达到三次提及后单独展示，不进入确定推荐。消息原文、判断与短候选词各有独立边界，模型不能通过返回词面直接添加票数。

装备标准名与核实的昵称属于运行数据；名称资料的来源和同版本精简元数据只用于核查。检索返回每条文本实际提及的标准名，不以全部目录喂给模型。响应先通过全目录校验，再检查该条候选子集，跨样本借用装备名会整批拒绝。含待确认陌生词的表达暂不发起请求，避免已知部分被错误提升为首选。

AI 从最多 2000 条有界记录中选取新鲜候选，过滤过期和不可靠名称后合并相同原文，每批最多三种。缓存以模型、模式、完整原文及海克斯候选为键，最多 64 项，按轮清空；同文消息各自保留回填票据。每条票据仍经过来源、轮次、匿名修订和时限检查。装备请求按实际首次请求时间及整轮四分之一间隔分散，四次请求、轮费用和会话费用三类限制分别展示。

共享 equipment.unknown 只含短原词和本轮条数／匿名标识数。equipmentDiagnostics 记录本地与 AI 分类数量、忽略原因和待确认阈值。本机 equipment-audit 提供最多 20 条原文及分类依据，前端切换模式或轮次后丢弃旧接口结果。

服务不保存 API 密钥至报告，不记录直播昵称或真实 UID。原始 XML 只读，导入数据中的消息标识与匿名来源使用重新加盐的哈希；样本原文保留用于语义验证。
