- 新增 Fluent 云白启动器，统一启动、托盘、设置和退出。
- 自带运行环境，首次完整解压后双击「梓有妙选.exe」即可使用。
- 支持应用内检查正式版本，点一下下载、校验并重新打开，收集期间不强制更新。
- 个人外观、背景、字号、加密密钥和长期黑名单独立保存，更新时保留。
- 新增首次上手提示、离线图文教程和腾讯问卷反馈入口，真实提交和微信提醒已确认。
- 控制台常显「显示桌面副屏」「启动器设置」及红色「退出全部」；桌面电源键单击后弹窗确认。
- 更新启动器展示图片，新增文案修改指南，方便维护者自行调整措辞。
- 海克斯、出装、点歌、桌面不抢焦点及原有快捷键继续保留。

首次使用建议先阅读启动器内的教程。更新会重启服务，本轮统计和本场灰名单随之结束，建议结束直播后更新。

反馈问卷已配置，提交后由溣符雨接收。可选 AI 需要首次在启动器填写 DeepSeek API Key，本包不附带密钥；新配置默认使用 Flash，装备 AI 开启，海克斯 AI 关闭。没有 Key 也可以先使用本地识别和点歌。

Windows 10／11 的 x64 电脑请下载便携 ZIP，完整解压后打开「梓有妙选.exe」。GitHub 的 Source code 为源码，不是自带运行环境的日常使用包。本版发布到 main，旧分支与标签保留。
