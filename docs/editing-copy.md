# 自己修改界面里的文字

只是换一句话，通常不用改程序逻辑。先备份文件，再搜索屏幕上已有的一小段文字，改掉对应内容即可。下面按启动器、教程和网页控制台分开说明。

## 先找对文件

| 想改的地方 | 文件 | 常见位置 |
| --- | --- | --- |
| 启动器中的标题、说明、按钮 | `launcher/MainWindow.xaml` | `Text="…"`、`Content="…"`、`Header="…"` |
| 启动器的运行提示、弹窗、托盘菜单 | `launcher/MainWindow.xaml.cs` | 中文字符串、`MessageBox.Show`、`menu.Items.Add` |
| 启动器的配置错误提示 | `launcher/UserSettings.cs` | 中文字符串 |
| 离线图文教程 | `public/guide.html` | `<h2>`、`<p>`、`<li>`、`<figcaption>` 之间的正文 |
| 控制台中一直能看到的标题、说明、按钮 | `public/index.html` | HTML 标签之间的正文，以及 `title`、`aria-label` |
| 控制台计票、名单、连接状态等动态提示 | `public/app.js` | 中文字符串、`textContent`、模板字符串 |
| 控制台启动器、更新、反馈等动态提示 | `public/application.js` | 中文字符串、`textContent`、确认提示 |
| 外观设置中的提示 | `public/appearance.js` | 中文字符串 |

文件名不需要记全。用 VS Code 打开整个项目文件夹，按 Ctrl＋Shift＋F 搜索屏幕上的一句话，就能看到它来自哪里。用记事本也可以，打开对应文件后按 Ctrl＋F 搜索。

先改一句，确认显示正确后再继续，比一次替换整页更容易检查。

## 例一：修改启动器的反馈说明

在 `launcher/MainWindow.xaml` 搜索「点右边填写反馈」。只改 `Text` 引号内的文字。

修改前：

```xml
<TextBlock Text="点右边填写反馈，溣符雨会收到提醒。" Style="{StaticResource Muted}"/>
```

可以改为：

```xml
<TextBlock Text="遇到问题可以在这里告诉我，我会收到提醒。" Style="{StaticResource Muted}"/>
```

`TextBlock`、`Style`、花括号和标签末尾不要改。其他地方的 `x:Name`、`Click`、`Grid.Column` 等也不是文案，保持原样。

XAML 中 `&#10;` 表示换行。需要写英文双引号时用 `&quot;`，需要写 `&` 时用 `&amp;`；普通中文标点可直接填写。不要删掉整段文字外面的英文双引号。

## 例二：修改教程的一段正文

在 `public/guide.html` 搜索「关闭副屏的叉号只关副屏」。只改标签之间的文字。

修改前：

```html
<strong>关闭副屏的叉号只关副屏。</strong>
```

可以改为：

```html
<strong>右上角的叉号只关闭副屏，不会停止统计。</strong>
```

保留 `<strong>` 和 `</strong>`，不要删掉附近的 `id="updates"`。页面上的目录链接靠这些编号跳转。`src` 是图片位置，`href` 是链接位置，`class` 是样式名称，也应保留。

HTML 正文中的 `&` 写成 `&amp;`，小于号写成 `&lt;`。中文引号「」可直接使用。

## 动态提示怎么改

如果在 HTML 中搜不到某句提示，再搜 `app.js` 或 `application.js`；启动器则搜 `MainWindow.xaml.cs`。

只替换中文字符串，不改两边的引号、反引号、逗号和括号。例如下面只改「已结束使用」这段中文。

```js
show('已结束使用。下次双击梓有妙选.exe 即可。');
```

如果一段文字含有 `${…}`、`{…}`、`\n` 等内容，它们可能是程序要填入的版本号、次数或换行，原样保留。不要把变量名一起删掉，也不要修改 `textContent`、`confirm` 或事件名。

不确定时先只改纯中文句子。保存后用原来那一步操作触发提示，检查版本号、次数和按钮是否还正常。

## 保存后怎样看到变化

保存时选择 **UTF-8** 编码。VS Code 右下角可以查看编码；不要用「ANSI」保存中文文件。

**网页控制台和教程。** 在源码目录运行服务时，保存 `public` 中的文件后刷新页面即可，通常不用重启服务。浏览器仍显示旧内容时，用 Ctrl＋F5 刷新。教程可以直接重新打开 `public/guide.html`，它不依赖联网。

**Windows 便携包。** 正在用 EXE 启动的服务读取的是包内 `app/public`，而不是另一份源码目录里的 `public`。临时预览可修改包内对应文件再刷新，但下次应用内更新会替换它；最终文案一定要同步到源码，重新打包后才会长期保留。

**启动器。** XAML 和 C# 会编译进 EXE，保存源文件不会立刻改变已打开的启动器。需要重新构建。在本项目已经配置好打包工具的电脑上，先选择「退出全部」，然后在项目目录打开 PowerShell，运行：

```powershell
./scripts/build-windows.ps1 -SkipPack
```

构建完成后，到 `dist/windows-stage` 打开「梓有妙选.exe」查看。这个目录用于本地预览，不是正式自更新包；给阿梓的新版本仍要按 [发布说明](releasing.md) 构建更新包并发布。

不要编辑 EXE 的二进制内容，也不用改 JSON 配置来替换启动器文字。

## 最后看一遍

检查修改后的文字是否太长、被截断，按钮和弹窗是否仍能操作。改了操作说明时，记得一起更新教程；改了按钮名称时，搜索旧名字，核对帮助里是否还有旧说法。

目前文案分布在这些界面文件中，少量修改按上面的办法就够用。如果以后经常改整套措辞，可以再把文案集中到一份外部文件；当前版本尚未采用这种方式，不需要先做额外配置。

演示视频的字幕与画面说明在 `scripts/make-demo.py` 的 `SCENES` 中，修改 `title`、`body`、`caption`、`details` 后重新运行脚本即可。制作流程见 [分享素材](share.md)。
