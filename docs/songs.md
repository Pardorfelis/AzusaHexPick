# 弹幕点歌

梓有妙选｜Azusa HexPick。项目发起与维护：溣符雨（B 站）。

## 使用

在操作台选择「弹幕点歌」，连接直播来源或选择歌回回放，再开始一轮。点歌默认收集 60 秒，可选 30、60、120、180、300 秒；Ctrl＋Alt＋F6 直接开始一轮 60 秒点歌，F9 锁定结果。

歌回 P1 从 46：30 开始，P2 全场可用于回放。候选片段按点歌文字密度定位，是否正在询问下一首仍以视频为准。两个分 P 的时间独立。

歌曲列表用于方便挑选。次数多不代表更应该演唱，主播可以选择自己想唱、会唱的任何一首。网页列表可滚动，桌面小窗可用滚轮或上下箭头查看后面的歌曲。

## 次数与候选

按点歌消息计次，同一个观众连续发送多条弹幕都计入。传输重复的同一个消息编号不会重复计数。一条弹幕重复写同一歌名只计一次，清晰列出不同歌曲时，每首各计一次。

至少出现两次的歌曲进入主列表。明确点歌但只出现一次的歌曲进入「单次点歌」区；仅出现一次的裸歌名先保存计数，待再次出现后展示。界面显示次数，不声称是独立观众人数。

已识别点歌弹幕条数与歌曲点歌次数是不同口径。一条弹幕可以点多首歌；单次裸歌名也会计入本轮消息数，但尚未展示。名单新增后会隐藏对应歌曲，不倒扣之前的消息总数。

本地识别裸歌名、连续重复歌名、书名号，以及想听、点歌、来首、可以吗、会唱吗等常见表达。未知明确请求保留原名并标为「待确认」。普通聊天、否定、唱过的历史和复杂歌曲讨论采取保守过滤。

历史曲目目录目前有 2313 个名称，主要参考 [510.azi.live 的历史歌切统计](https://510.azi.live/data?view=songstats)及真实歌回请求。它不是官方完整歌单，更不代表主播当前会唱或愿意唱。新歌可以通过明确点歌表达进入候选；未收录的裸歌名、错别字、未经确认的简称和复杂条件仍可能漏识别。同名歌曲按标题汇总，暂不区分歌手版本。来源见 [歌曲目录口径](../validation/song-catalog-sources.md)。

## 本场灰名单

在操作台歌曲旁点击「本场不再显示」，或者在桌面小窗该行点击「略过」，即可加入灰名单。适合本场已唱过或本场不想唱的歌，不需要手动输入名称。

加入后立即从当前显示中隐藏，之后的轮次继续过滤同名歌曲。开始新轮、切换来源或回放跳转不会清空本场灰名单。可以在操作台名单中点击「恢复显示」。过滤期间的点歌不会补计；本轮加入前已经计入的请求在恢复后可以重新显示。

下一场歌回开始时，点击「开始新场歌回」并确认，清空灰名单和当前点歌轮。真正重启服务也会得到独立的新场次。网页刷新、关闭小窗或在服务仍运行时再次点击启动脚本不会自动清空名单，避免误丢本场设置。黑名单不受换场影响。

## 黑名单

在操作台手动输入完整歌名，选择一周、一个月、三个月、半年、一年或永久，再点击加入。同名再次加入会更新期限，也可以提前移除。

一周为七天。月、季度、半年及一年按北京时间的日历计算，月末超出目标月份时取目标月最后一天，并保留对应时间。期限到达后自动解除并从本机名单删除，包括没有收到弹幕的空闲时段。

黑名单写入本机 data/song-blacklist.json，不进入 GitHub 或便携包。写入失败不会假装添加成功；过期记录无法写盘时仍解除过滤并显示提醒。文件损坏时明确报错，避免静默丢失已有名单。

## 边界

点歌功能当前使用本地识别，不向 AI 发送歌回弹幕、不产生模型费用。原有装备与海克斯 AI 开关仍只作用于各自模式。

手机与网页只读副屏不提供名单操作；本机操作台和桌面小窗可以管理灰名单，黑名单与换场入口位于操作台。最近最多 20 条点歌识别依据仅本机可读，不进入共享结果。

每轮最多保留 500 种歌曲，本场灰名单和黑名单各最多 1000 首。达到上限会明确提示，不以部分结果代表全部弹幕。所有名单仍无法替代主播本人对歌曲的选择。
