# 外观与本地背景

v0.6.0 保留计票与操作布局，外观独立于轮次、AI、名单及来源连接。项目发起与维护：溣符雨（B 站）。

## 选择款式

点击页头「外观」，按控制台、网页副屏、桌面窗三个页签分别选择主题，保存后即时生效。选中款式有轮廓与按下状态；键盘可用左右方向键切换页签，Esc 关闭面板。

| 款式 | 使用感受 |
| --- | --- |
| 梓色雾光 | 默认夜蓝与梓紫，适合晚间游戏 |
| Fluent 云白 | Windows 11 风格，明亮浅色层次 |
| 暖纸杏桃 | 温暖纸色，柔和的平整表面 |
| 月下樱 | 墨蓝柔粉，适合晚间歌回 |
| 薄荷轻语 | 雾绿浅色，清爽阅读 |
| 石墨静夜 | 中性深灰，弱化边框 |
| 跟随系统 | 浅色使用 Fluent 云白，深色使用梓色雾光 |
| 经典工作台 | 原有蓝灰样式，随时回退 |

「同步此主题到三处」只同步款式，背景和桌面倍率独立保留。网页跟随浏览器的系统配色偏好，Windows 桌面读取应用主题偏好；桌面会在两秒内检查系统变化。

桌面从操作台选择主题，保持原有坐标及按钮区域。Fluent 云白采用浅色控件层次和内容圆角，系统支持时请求外框圆角。外框效果取决于 Windows 版本及兼容性，没有启用真实 Mica 或 Acrylic 透明材质。

## 背景图库

内置「无背景」和「梓色凝望」，默认图片由维护者提供。界面不展示默认图的画师姓名，作者与版权说明由维护者在正式公开的 README 中补充；素材来源记录仍保留。

在控制台或网页副屏页签点击「导入图片」，选择静态 JPG、PNG、WebP，填写名称、画师及可选来源。单张最大 10 MB，最大边长 8192 像素，最多 2000 万像素；拒绝动图和可检测的损坏结构。最多保留 80 张自定义背景。同一文件再次导入会复用原条目。

自定义背景可修改署名或删除。删除当前背景会将正在使用它的网页位置切回「无背景」。内置图不可删除。图库保留原文件，通过 CSS 亮度、饱和度、柔化与遮罩调整显示，不修改像素。

「背景显著程度」提供安静、柔和、清晰三档，输入与结果区保留稳定底色。默认轻微鼠标视差，位移长度最多 8 像素；仅在鼠标设备、页面可见且动效开启时响应指针，没有空闲动画循环。

页头「暂停动效」同时暂停 GIF 和背景视差，记住控制台偏好。系统减少动态效果时自动停用。桌面保持原有静态图片，不使用背景图。

## 网页副屏与手机

网页副屏默认无图片、外层透明，可用于 OBS 浏览器来源，结果区域使用自身底色。可从网页副屏页签单独选择图片。截图可能把透明区域呈现为白色，实际 OBS 合成应按自己的直播场景检查。

手机仍为配对只读页，主题可同步读取；所有外观写入仅限本机。自定义背景需有效配对令牌才能从局域网读取。

## 保存与迁移

设置及图库索引保存于 data/appearance.json，导入图片保存于 data/backgrounds，桌面尺寸与倍率继续使用 .runtime 独立配置。保存先写临时文件再替换，失败时不替换已有设置。

个人配置、导入图片、黑名单和密钥不进入 Git 或便携包。更新代码时保留 data 目录即可保留外观。配置损坏时提示并回退，重新选择后可保存正常配置。
