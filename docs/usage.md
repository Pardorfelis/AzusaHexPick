# 使用与验收说明

项目发起与维护：溣符雨（B 站）。副屏标题为「梓有妙选｜Azusa HexPick」，操作台与副屏在结果区域底部保留简洁署名。

## 第一次使用

Windows 10／11 的 x64 电脑可选择 v0.7.1 安装版或便携版，功能相同，均自带 Node、Python 和 .NET，不需要另装。

**安装版。** 运行安装包，按照向导选择安装位置，默认勾选「创建桌面快捷方式」。安装完成后，从桌面的「梓有妙选」打开，点击「开始使用」。默认使用当前用户目录，无需管理员权限；其他位置需要当前用户可以写入。

**便携版。** 将 ZIP 完整解压到固定文件夹，找到根目录的「梓有妙选.exe」，右键选择「发送到 → 桌面快捷方式」。Windows 11 如果没有这一项，先点「显示更多选项」。以后从桌面快捷方式打开，保留完整文件夹，不要只将 EXE 移到桌面。

海克斯技能选择和弹幕点歌统计目前较成熟，可以优先试用。海斗装备建议仍在测试中，部分非官方别称可能未被本地知识库收录，启用 AI 也不能保证较高的准确率。

启动后网页控制台和桌面副屏一起打开，启动器收进右下角托盘。重复双击会唤回已有启动器，不会另开一套服务。控制台默认选择「直播间」，阿梓房间 510 已填好；未开播时再切到「回放体验」练习。

如果要启用 AI，在启动器「首次设置与偏好」中粘贴 DeepSeek API Key 并保存一次。密钥使用 Windows 当前用户加密，后续自动读取。新配置默认使用 Flash，装备 AI 开启，海克斯 AI 关闭；没有密钥时保留本地识别和点歌。更换电脑或 Windows 用户后，需要重新配置密钥。

教程可从启动器「使用教程」或控制台的教程入口打开，断网也能看。交付包要保留完整目录，不能只复制 EXE。源码直接运行的环境要求另见 [项目首页](../README.md)。

## 操作台布局

页头下方常驻「显示桌面副屏」「启动器设置」和红色「退出全部」按钮。更新与完整教程在可展开的「更新与帮助」中；「问题反馈」另有入口。关闭桌面窗后，可从常驻按钮或托盘再次显示。

可从「外观」选择六套主题、跟随系统或经典工作台。三处独立保存，可同步主题；首次使用交付包默认为 Fluent 云白，已有设置继续保留。背景、署名和保存位置详见 [外观说明](appearance.md)。「暂停动效」同时暂停视差与 GIF。网页副屏默认外层透明，桌面尺寸、字号和不激活行为保持不变。

建议使用宽度不小于 1280 像素的桌面窗口。左侧先选择来源和统计方式，右侧结果区随页面滚动保持可见。回放的播放按钮位于定位输入框下方，候选片段位于其后。点歌时下方显示灰名单与黑名单，AI 设置按模式显示。

窄窗口按来源、轮次、附加设置、结果的顺序排列，支持键盘操作和可见焦点。副屏标题仍为「梓有妙选｜Azusa HexPick」，署名位于页脚。系统启用减少动态效果时，连接、锁定与歌曲入列不播放动画，仍保留文字和颜色状态。

Windows 原生置顶窗同步配色与素材，计票格紧凑排列，歌曲仍可翻页、滚动与点击「略过」。操作台页头有「暂停动效」按钮，再点可启用；系统减少动态效果时自动显示静态图。控制台与桌面窗的「溣符雨 · 维护」使用粉色强调。设计与素材来源见 [界面说明](design.md)。

## 开始与锁定轮次

选择模式、口径和收集时长，再开始新轮。没有连接时不会收集。时间到达自动锁定，手动锁定后不接受新建议。

快捷键为 Ctrl＋Alt＋F7、F8、F9，分别开始海克斯轮次、开始装备轮次和锁定。只有快捷键成功注册后，操作台才显示助手已连接。

刷新技能之后必须新开一轮。不能把刷新前后的数字建议混在一起。单靠文本无法判定每个新消息究竟回复了哪个延迟画面，这仍然是实战待验的问题。

暂停回放会锁定当前结果。跳转、换分 P 和重新播放都会使用新的回放代次，并清空本轮。这里的跳转不模拟直播中断消息补回。

## 两种计数口径

有效弹幕条数是默认口径。每条消息只统计一次，但同一匿名来源重复发言仍增加条数；改口后的新消息也增加一条建议。

匿名标识实验口径保留同一匿名来源本轮最新的有效建议。普通闲聊不撤销原建议；明确反对会撤回该来源当前匿名支持，并使旧的未决解释失效。条数口径保留历史支持消息，不因之后反对倒扣。缺失匿名身份的消息不会被合并成一个人，也不会计入匿名标识数。

海克斯分层识别选择与刷新动作。先归一化空白、全角和大小写，只移除受限的边缘标点，保留中间的小数点和多选分隔。纯指令直接统计；同数字刷屏如 222222、２２２、222！每条只算支持 2 的一票。

新增 d、D、dddddd、全 d 了、全刷了等明确全部刷新表达。12d、13d、23d 分别支持刷新两个对应选项，反序 21d、31d、32d 会规范化。每条消息只统计一个完整动作，12d 不拆成两条 1d 和 2d；前三个选择、三个单项刷新、三个双项刷新及全部刷新共十种动作。裸 123d、混合选择和刷新、比分及数字量词不猜测票意。

通用短句使用受限句式识别，如直接拿 2 啊、必须 2、2 是无敌的、这不选 2？。明确的刷新 1、刷 2、1 刷一下分别归为 1d、2d、1d。不是见到数字就统计；否定、多选、回顾、条件、普通提问和数字单位会保守拒绝，2 万伤害、1.2、23 都行不会加票。

2 收集者、2 然后收集者等数字与具体名词的组合，不写成通用推荐词，仅保留为未决表达。珠光、法爆等无编号技能名忽略，不猜测当轮选项对应关系。某些明确但不在句式范围内的表达仍可能漏计。

操作台、副屏和手机显示收到、计入与未决三个数量。收到是轮内通过来源、时间和消息去重检查的消息，计入是累计确认的有效建议。海克斯未决只包含数字相关复杂表达，装备未决包含尚未确认的出装表达；未决数量包含失败或被淘汰的记录。闲聊和明确拒绝另行忽略，三者不要求相加相等。匿名口径下十种动作的票数合计可能小于累计计入数量。

操作台的“查看最近识别依据”可读取最近最多 20 条海克斯或装备相关样本，显示规则类别与是否计票。样本原文只在本机接口读取，不进入副屏和手机共享快照，不是完整日志。跳转或开新轮会清空。装备的计入包括明确分类的建议；前三项只采用当前购买，后续、条件、备选和反对不能混成首选。

## 装备和 AI

首选、反对、后续计划、条件和多个备选分别处理。面板的前三项只来自明确首选，歧义不强行分票。正式名目录来自 Riot 官方 Data Dragon 16.19.1，去重并排除空串、任务、奖励及伪物品，保留正常组件、消耗品和变形装备。昵称另行维护，不根据英雄、经济或模式判断可购买性。

绿甲、蓝盾等经过核实的常见别名，以及明确购买、换装短句，先由本地归并。歧义简称不凭字形相似硬映射；复杂句由可选 AI 判断购买意图，输出只允许本次从文本检索得到的正式名候选。

当前目录为 411 个正式名称、102 个昵称，另列 13 个歧义原词。名称来源和过滤边界见 [装备目录核查](../validation/equipment-expansion-sources.md)。名称覆盖不能保证各种新梗都被识别，也不等于当前模式的购买白名单。

未知名称不再只呈现一个未决总数。已有购买意图或短装备词形的原词，在同轮当前未决记录中至少出现 3 次时，会展示原词与提及数，最多三项；桌面紧凑窗最多两项。匿名口径要求至少 3 个不同标识，缺少身份不算匿名提及。已改口或已确认的记录不再形成这类线索。该区域明确标为待确认，不参与首选、有效支持票或领先项，也不代表确定的购买建议。其他陌生表达仍可能漏识别，结果不能代表全部观众意见。

装备 AI 与海克斯 AI 有两个独立开关。交付包首次配置密钥后默认开启装备 AI，海克斯 AI 关闭；已保存的偏好按原设置恢复。源码开发模式仍默认关闭。启用后只发送本轮需要解释的文本、允许范围或文本已有的唯一候选指令，不附加昵称、UID、匿名标识或直播登录凭据。弹幕原文本身可能包含提及的人名。DeepSeek 密钥仅位于本机接口请求的鉴权头，不进入模型提示词或结果快照。

装备 AI 首次有合适候选时即可处理，后续请求间隔为本轮时长的四分之一，避免开头连续耗完四次额度。每批最多三种不同原文，相同原文可以合批；确认和不确定解释都在本轮缓存，最多 64 项，换轮或切换模型清空。缓存复用仍逐条核查身份修订、轮次和截止时间，每条弹幕最多形成一条解释。

仅处理接收后五秒内且还剩至少 1.2 秒的候选。已过期的未决不会堵住新建议；尚未映射的陌生词或歧义原词继续待确认，不为了识别其中一个已知装备而忽略剩余备选。操作台显示本轮请求数、累计费用及当前策略，如等待下一处理时段、无可靠名称映射、超过预算或剩余时间不足。请求达到上限后仍保留本地结果和待确认名称。

海克斯 AI 仅在收集至少 3 秒、最后 7 秒且尚有至少 1.2 秒时尝试近期未决表达。本地明确建议累计达到 20 条就跳过，在途结果返回时也再次检查。20 条只是调用策略，不是统计置信度或精确观众人数。模型只能确认候选指令或保留不确定，不能映射无编号技能名，不能生成另一选项或票数。早于处理时限的旧表达不再补判。

可以选择 deepseek-flash 或 deepseek-v4-pro，两者共用官方平台密钥。关闭思考模式，要求结构化输出，并校验完整字段、编号和装备范围。模型不能修改票数。

每轮最多 4 次请求，并设置 0.10 元的保守估算预算；每次服务运行设置 1 元的保守预留预算。按官方高峰价格预留输入和输出费用，无法确认返回用量时标为未知并暂停。估算预算不是服务端账单上限，超时也不等于服务端停止计费。

模型失败后暂停且不自动重试付费调用。本地已识别结果继续显示。旧轮、旧连接、同人改口之前和超过时限的结果不回填。

## 桌面副屏与手机

桌面小窗默认放在副屏工作区，没有副屏时放在主屏右侧。拖动标题可摆放，右上角叉号只关闭小窗，不结束计票服务。点电源图标会弹出「确认退出全部吗？」；选择「取消」继续使用，选择「确认」才结束服务和副屏。这个确认弹窗会接收鼠标操作，平常的副屏仍保持不激活机制。小窗不提供游戏操作。快捷键冲突时会明确显示不可用，仍可用网页控制。

从 v0.5.1 起，可以拖动窗口四条边缘或右下角的斜线调整宽高。拉高窗口会显示更多歌曲；拉宽窗口能显示更长的歌名。窗口有最小尺寸，避免统计内容和按钮被挤掉。

底部「显示」旁的加减按钮调整整个窗口的文字与按钮倍率，范围为 100％ 至 200％，每档 25％；「默认」恢复 480×760 像素及 125％ 倍率。点歌标题基准为 12 磅，125％ 显示时为 15 磅，150％ 时为 18 磅。远距离看副屏时建议先试 150％，再根据视距调整。扩大倍率时窗口会相应增大，并依据当前屏幕工作区限制最大倍率，避免内容超出屏幕。随后仍可独立调整宽高。

交付包的窗口尺寸与倍率保存于用户数据目录的 runtime/desktop-display-5178.json，重启后恢复；源码开发模式仍使用项目内 .runtime。该设置不进入仓库或便携包，与灰名单、黑名单及统计结果相互独立。启动参数 --width、--height、--zoom 可临时指定显示配置，--zoom 使用 1、1.25、1.5 等数值。

同一项目和端口的桌面面板只允许一个实例。停止服务后，面板在持续无法连接约 10 秒时退出并释放快捷键；主播下播或弹幕数据源断连不会关闭仍可连接的本机面板。

实际独占全屏可能覆盖其他置顶窗口，需要在阿梓实际游戏设置中确认。首次验证请观察游戏是否保持焦点、弹幕和礼物是否仍可阅读，以及能否在约 2 秒内看出领先项和并列。

手机需要与电脑处于同一局域网。在启动器设置勾选手机模式并保存；服务已经运行时会提示需要重启，正在收集时应先结束本轮。随后从操作台复制推荐配对地址。其他网络地址折叠显示，不再并列展示所有虚拟网卡地址；无法判断首选网络时，按提示选择实际使用的 Wi-Fi 或有线网络。换网后刷新地址。链接只在本次服务运行中有效，重启后失效。手机页不能控制轮次、名单、更新或启用 AI。源码开发方式仍可使用「启动手机模式.cmd」。

默认本机模式不会开放局域网访问。程序不会自动添加防火墙规则。实际手机访问、锁屏恢复和长时间亮屏需要用户验收。

## 退出、更新与个人设置

结束使用时，从控制台红色「退出全部」、托盘菜单或副屏电源图标退出。服务运行时关闭启动器窗口会收起到托盘；关闭副屏叉号只关副屏，两者都不等于停止整个程序。

启动器会在启动时异步检查正式版，控制台「更新与帮助」也可手动检查。发现新版后显示版本和说明，由使用者选择「更新并重新打开」或「稍后」。收集期间不能应用更新；下载完成后会再次检查，若又开始了新轮，保留下载成果，等本轮结束后再操作。

程序下载并校验更新包，再关闭自己启动的服务与副屏，更新后重新打开。不会终止无关程序。网络、校验或空间检查失败时可继续使用旧版，稍后重试。仅推送源码不会通知客户端，维护者需要发布正式更新包和清单，见 [发布说明](releasing.md)。

主题、导入背景、显示字号、长期黑名单和加密密钥存放于 `%LocalAppData%\AzusaHexPick\UserData`，独立于软件解压目录，应用更新会保留。更新会重启服务，本轮统计与本场灰名单结束；建议结束直播后更新。

旧脚本版设置可从启动器「导入旧版设置」迁移。先退出旧服务，选择旧项目文件夹；程序校验并备份已知设置后导入，不改原目录，也不覆盖已经存在的新设置。密钥不从旧 `.env.local` 导入，仍需在启动器填写一次。

## 问题反馈

展开控制台「问题反馈」，点击「填写问题反馈」，在问卷中描述问题并提交。加载失败时可用备用链接打开 [腾讯问卷](https://wj.qq.com/s2/28082013/eqvo/)；启动器也有入口，服务没有启动时仍可反馈。

问题描述必填，类别和诊断信息选填，不要求手机号或邮箱。点「查看诊断信息」后可自行复制到问卷，程序不会自动提交。诊断只含版本、模式、连接和运行状态等必要信息，不含密钥、完整弹幕、昵称、配对令牌或私人路径。以问卷显示提交成功为准，提交后我会收到提醒。后续沟通仍通过原有联系方式完成。

需要自己调整这些文字时，见 [文案修改指南](editing-copy.md)。

## 尚需现场验证

未开播时可用回放和已保存历史弹幕检查。以下项目仍需要实际游戏、主播或手机环境：

1. 打开 P3 的 01：53：50，选择海克斯、条数口径、60 秒并播放，预期收到 150 条、计入 90 条、选择 2 为 64 条、全部刷新为 1 条。保持两个 AI 开关关闭即可验证本地规则。
2. 游戏保持前台，用 Ctrl＋Alt＋F7、F8、F9 开轮和锁定，确认游戏没有失去焦点，副屏仍能看弹幕和礼物，并能在约两秒内看清领先项和并列。
3. 下次阿梓明确询问出装时开启装备 AI，再用 Ctrl＋Alt＋F8 开轮。实战优先试 10～20 秒，记录收到、计入、未决、本轮请求数、前三项及待确认原词，并点开最近识别依据核对两三条。60 秒适合离线复核，不能用它代替限时决策测试。
4. 若使用手机，再在同一局域网确认配对访问、只读限制及锁屏恢复。

主播画面已知约有 5 秒延迟，提问和观众回复仍可能跨过轮次边界。请记录提问、开轮、首条建议、结果可读和最终选择的时间；程序不会自动减去五秒或承诺消除旧建议。

回放和构造异常可以检查状态逻辑，不能替代阿梓真实征求建议时的时效测量。还需观察主播提问、首条建议、面板可读、最终决定的时间，并记录新轮旧票混入程度。

连接短时成功不保证直播高峰全量接收或数小时稳定。游客接入依赖公开客户端协议，错误或鉴权拒绝会明确停止，不绕过验证。
