## 官网与演示

官网首屏标题为「海斗选哪个技能？下一首唱什么？」，先展示海克斯和点歌的实际结果，再介绍如何打开软件。海斗装备建议标注「测试中」，不承诺新昵称或复杂表达都能准确识别。

演示沿用实际界面截图和字幕，回放来源全程标明。它是截图字幕演示，不是鼠标录屏；不展示真实 API Key、配对令牌、私人路径及未脱敏的观众身份。

v0.7.1 演示加入《Canon in D Major》配乐，保留录音作者、来源、许可及剪辑说明。该版本由 Kevin MacLeod 提供，不能把其他录音的授权套用到它上面。音源及许可见 [作者页面](https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1100301)。

[演示视频](https://github.com/Pardorfelis/AzusaHexPick/releases/download/v0.7.1/AzusaHexPick-v0.7.1-demo.mp4)、[封面](https://github.com/Pardorfelis/AzusaHexPick/releases/download/v0.7.1/cover.png) 和 [字幕](https://github.com/Pardorfelis/AzusaHexPick/releases/download/v0.7.1/demo.srt) 随正式版本分发；官网同站提供视频，不以访问 GitHub 作为观看前提。

| 顺序 | 画面 | 要让人看懂什么 |
| --- | --- | --- |
| 海克斯 | 回放弹幕与副屏的选择、刷新统计 | 弹幕太快时可以直接看哪项更多 |
| 点歌 | 主列表、单次候选及点击「略过」 | 想唱哪首自己挑，唱过的本场先不再显示 |
| 出装，测试中 | 装备昵称归并后的结果 | 常见称呼可以汇总，新别称仍可能漏掉 |
| 开始使用 | 桌面快捷方式、开始使用、托盘入口 | 安装版和便携版都无需另外安装开发工具 |
| 后续维护 | 反馈与更新按钮 | 遇到问题可以告诉我，新版点一下更新 |

重做演示时修改 `scripts/make-demo.py` 的 `SCENES` 文案，准备确认有效的截图清单，使用 `--manifest` 指定该 JSON 文件。清单包含 `confirmed: true` 和 `sources`，每项提供项目内 `path`，可选 `crop` 为左、上、右、下四个像素坐标；来源键为 hex、songs、equipment、launcher、panel、feedback、update。需要 Pillow、微软雅黑字体，以及脚本 `TOOLS` 指向的 FFmpeg。具体配乐参数以脚本帮助为准，不要换用来源不明的音频。

## 三个输出目录怎样区分

| 目录 | 内容 | 是否直接发给使用者 |
| --- | --- | --- |
| `dist/releases` | 已核验的 v0.7.1 安装向导、便携 ZIP 和更新包；旧版另存于 `dist/archive/v0.7.0` | 完成官网远端验收后只展示安装向导和便携 ZIP；更新包由程序读取 |
| `dist/delivery` | 演示视频、封面、字幕及制作记录 | 视频、封面和字幕可以发布；制作记录留在本机 |
| `dist/windows-stage` | 编译后的启动器、运行环境、网页和服务，供打包前检查 | 不直接发；这是本地预览与构建中间目录 |

此外，`.runtime/v071-preview-releases` 单独存放 v0.7.1 本地预览安装包和更新包，与上述三个目录分开。它不进入官网正式下载、GitHub Release 或客户端正式更新源。同名便携 ZIP 仍需检查包内版本，不能只看文件名判断。

给梓神的官网只保留两个软件下载选择：推荐的安装版，以及便携版。不要把整个 `dist` 文件夹、源码 ZIP、NUPKG 更新包或未校验的测试版本发给她。
